## 3쪽 정면 비율 분석 (카드 한 줄 설명, 22~30자)
- 종횡비 1:1.50 → 기준보다 세로 길이가 조금 긴 편
- 상:중:하 1:1:0.8 → 상안부와 중안부는 균형적이며, 하안부가 상대적으로 짧음
- 눈 너비 1:1.0:1.0 → 눈 너비와 미간의 간격이 균형적으로 배치
- 눈 위치 1:0.9 → 눈이 상대적으로 살짝 낮게 위치한 편
- 코 위치 1:0.7 → 아랫입술부터 턱끝까지의 구간이 짧은 편
- 입 위치 1:1.5 → 입술 아래에서 턱끝까지의 길이가 짧아 하안부가 간결함
- 정면 해석 제목: 긴 얼굴 비율 + 균형적인 미간 + 짧은 하안부
- 정면 해석 본문: 전체적인 얼굴은 세로로 조금 긴 편이지만, 상·중안부는 균형적이고 하안부가 상대적으로 짧습니다.\n눈 사이 간격은 안정적이며, 광대에서 턱끝으로 좁아지는 윤곽이 부드러운 인상을 형성합니다.

## 4쪽 측면 비율 분석 (PROFILE 4 AXES — 제목은 '부위 : 요약 + 요약', 본문 2줄)
1. 이마 · 눈썹뼈 : 완만한 이마 곡선 + 부드러운 눈썹뼈 / 이마가 자연스럽게 둥근 곡선을 이루며,\n눈썹뼈의 돌출감이 강하지 않아 부드럽게 이어집니다.
2. 콧대 · 코끝 : 자연스러운 콧대 + 갸름한 코끝 / 콧대가 완만한 굴곡을 이루며,\n코끝은 적당한 돌출감을 보입니다.
3. 입술 : E-line에 가깝거나 살짝 앞쪽에 위치한 입술 / 입술이 코끝과 턱끝을 잇는 기준선에 가까우며,\n약간 앞으로 나온 형태로 보입니다.
4. 턱끝 · 턱선 : 짧은 하안부 + 부드러운 턱끝 / 입술 아래부터 턱끝까지의 구간이 비교적 짧으며,\n턱선은 완만하게 이어집니다.
- 측면 해석 제목: 완만한 곡선 + 자연스러운 입체감 + 간결한 턱끝
- 본문: 이마부터 코끝까지 부드러운 곡선이 이어지며, 입술은 E-line에 가깝거나 살짝 앞쪽에 위치합니다.\n턱끝의 돌출감이 강하지 않고 하안부가 짧은 편이므로, 입술의 과도한 볼륨 확장보다는 본래 윤곽을 살리고\n코와 턱끝의 균형을 자연스럽게 유지하는 스타일링을 추천합니다.
